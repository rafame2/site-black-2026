# Black Unificada 2026

Página estática responsiva da campanha da Egrégora Unificada, com Radiestesia Unificada e Apometria Unificada.

## Estrutura

- `public/index.html`: conteúdo e metadados SEO/Open Graph.
- `public/styles.css`: identidade visual e layout responsivo.
- `public/script.js`: carrossel manual e programação de preços.
- `public/black-unificada-share.svg`: imagem para compartilhamento.

## Publicação

O conteúdo está em `public/` e pode ser publicado pelo GitHub Pages com uma workflow de GitHub Actions. Os checkouts ainda precisam ser conectados e testados; por isso, os botões de compra permanecem desabilitados. As condições de garantia e parcelamento dependem da confirmação no Hotmart.

Os depoimentos em vídeo e o relato de Sandra Leite não foram incluídos; dependem dos arquivos e das autorizações correspondentes.
